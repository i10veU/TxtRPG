# Phase 261 — 정보·소문 시스템

## 목적

NPC 자율 행동과 사건 Trigger 사이에 플레이어가 직접 탐색할 수 있는 정보층을 추가한다.

## 구현

- `world.rumors` 상태 추가
- NPC event signal 발생 시 소문 자동 생성
- 소문마다 출처 목록, 첫 발견일, 마지막 확인일, 확인 횟수, 신뢰도 저장
- 서로 다른 출처가 같은 정황을 확인하면 신뢰도 상승
- IndexedDB 저장 상태 정규화와 호환
- `소문` / `소문목록` 명령 추가
- 6번 PC 정보 패널에서 소문·신뢰도·출처 표시
- 100×200px 초미니 화면의 기존 레이아웃을 유지
- 긴 서사는 내부 스크롤로 확인할 수 있도록 UI를 안정화

## 플레이 루프

NPC 행동 → event signal → 소문 생성 → 여러 출처에서 확인 → 신뢰도 상승 → 사건 Trigger → 플레이어가 사건을 발견하고 선택

이 구조를 통해 플레이어가 퀘스트 게시판을 순서대로 소비하는 대신 세계에서 들은 정보로 목표를 스스로 구성할 기반을 만든다.

## 한계

현재 소문은 NPC event signal을 중심으로 생성되며, 정보의 편향·위조·전파 거리·시간에 따른 망각까지는 아직 모델링하지 않는다. 다음 단계에서 NPC 목표와 관계망을 연결해 같은 정보가 누구에게서 어떻게 퍼지는지를 확장할 수 있다.

## 검증

- NPC event signal의 소문 생성
- 소문 출처 기록
- 복수 출처 확인 시 신뢰도 증가
- `소문` 명령 출력
- 세이브 상태 정규화
- CI 회귀 테스트 연결
- 초미니 UI 스크롤 회귀 수정
