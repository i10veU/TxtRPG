# Phase 257 — 세력 압력과 연쇄 사건

## 구현

기존의 NPC → 세력 관계를 정적인 평판 수치에서 세계 상태에 반응하는 동적 관계망으로 확장했다.

- 곡물 공급, 치안, 긴장도, 행정 신뢰, 소문 압력이 세력 관계에 영향을 준다.
- 세력 관계 변화는 하루 단위로 계산되어 30분 NPC 틱마다 과도하게 누적되지 않는다.
- 두 개 이상의 세력이 적대적 상태이고 도시 긴장도가 높으면 `factionConflict`가 활성화된다.
- 이 조건은 `갈라진 도시의 이해관계` 사건을 생성한다.
- 사건의 중재, 편승, 공개 폭로 선택은 다시 세력 관계와 긴장도에 영향을 준다.
- 기존 `eventSignals`, NPC 일정, IndexedDB 저장 구조와 호환된다.

## 세력 반응

| 세력 | 주요 압력 |
|---|---|
| 상인회 | 곡물 공급 |
| 경비대 | 치안 / 긴장도 |
| 기록관 | 행정 신뢰 |
| 농촌 대표단 | 곡물 공급 |
| 여관망 | 소문 / 긴장도 |
| 노동자 | 치안 / 긴장도 |
