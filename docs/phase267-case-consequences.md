# Phase 267 — 사건 Consequence와 조직 관계 피드백

조직 충돌로 열린 사건의 플레이어 선택이 다시 조직 관계와 목표 압력에 영향을 주도록 연결했다.

`faction-conflict`의 중재 선택은 조직 관계 점수를 회복시키고 모든 조직의 목표 압력을 높인다. 공개적인 편들기는 조직 관계를 악화시키고 특정 조직의 목표 압력을 높이거나 낮춘다. 기록 공개는 기록관·여관망·상인회 사이의 관계와 목표 압력을 별도로 조정한다.

따라서 현재 핵심 루프는 다음과 같이 연결된다.

자율 NPC 행동 → 조직 의사결정 → 조직 협력/충돌 → 사건 Trigger → 플레이어 선택 → 조직 관계/목표 압력 변화 → 다음 NPC 행동

검증은 `tests/phase267-case-consequences.js`에서 세 가지 선택 결과와 상태 정규화를 확인한다.
