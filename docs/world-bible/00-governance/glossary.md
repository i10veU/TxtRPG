# 용어

| 용어 | 뜻 |
|---|---|
| 정본 (Canon) | 소유자가 승인한 세계의 사실 (`canon-policy.md`) |
| 세계 (World) | 독립된 인과 구조를 가진 하나의 세계. 서로 다른 세계는 명시적 연결 없이 결과를 공유하지 않는다 |
| 생 (Life) | 플레이어 캐릭터 한 명의 일생. 죽으면 끝나고, 세계는 남는다 |
| 후계자 | 같은 세계에서 이어서 시작하는 다음 생의 캐릭터. 이전 생의 지식·소지품·관계를 물려받지 않는다 |
| 흔적 (Trace) | 생이 끝난 뒤에도 세계에 남는 결과 — 직접적 / 역사적 / 사회적 / 간접적 / 희미한 흔적 |
| 진실과 정보 | 세계의 실제 상태(진실)와 캐릭터가 아는 것(정보)은 별개의 층이다. 정보에는 출처와 신뢰도가 있다 |
| 지역 (Region) | 여러 장소를 묶는 지리·사회 단위 (`03-geography/`) |
| 장소 (Site) | 플레이어가 머무르고 행동하는 단위 |
| 조직 (Faction / Organisation) | 목표·자원·영향력을 가진 집단. 마을 공동체, 도적단, 길드, 왕국 등 |
| 구현 ID | 게임 데이터팩의 식별자 (`loc_*`, `npc_*`, `org_*`, `fact_*`, `rum_*`). World Bible 항목은 해당되는 구현 ID를 적는다 |
| 정본 원칙 | 세계의 사실이 아니라 설정을 만드는 방법으로 승인된 것 — 연속성 원칙(WB-0005), 주제 원칙(WB-0007), 명명 원칙(WB-0013) |
| 범위 제한 승인 | 추천의 일부만 정본으로 한 승인. 나머지는 `Draft`로 남는다 (WB-0009, WB-0012) |
| 메가월드 | 여러 세계와 장르를 담는 TxtRPG 전체 설정의 범위 (WB-0014). 세계의 수·구조·기원은 미결 |
| 설정의 네 층 | 세계의 진실 / 세계 안의 주장·믿음 / 플레이가 정하는 역사 / 게임·균형 값 (`canon-policy.md`, WB-0015) |
| 정보의 기울기 | 정보는 근원에서 멀어질수록 느려지고, 드물어지고, 변할 수 있다 (WB-0016 N-06) |
| 접합부 원칙 | 모든 수수께끼가 다른 세계로 이어지지는 않으며, 세계 사이의 연결에는 명시적 원인이 필요하다 (WB-0016 N-08) |
| 작업용 가정 | 콘텐츠 설계의 기본값으로 채택한 `Draft`. 정본이 아니다 (W-01 ~ W-12, WB-0016) |
| 겹이름 | 한 대상이 동시에 가지는 여러 이름의 층 — 일반명사·고장 이름·공식 이름·바깥 이름·별칭·옛 이름 (WB-0017 G-01) |
| 명명 도구 | 한 문화의 고유명을 만드는 규칙 묶음. 고유명보다 먼저 정한다 (WB-0017 G-05) |
