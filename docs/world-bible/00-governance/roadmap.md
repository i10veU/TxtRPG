## 6. 추상 로드맵 (WB-0023 결정 2 — 그대로 둔다)

- 지금까지: V2 Core → 첫 세계 → 지역 확장 → 성읍 → 정보·교역 연결(Slice 1 ~ 7) → 왕도 진입(Slice 8) → RPG Depth → 플레이어 없이 움직이는 세계 → Multi-run / World Memory 강화
- 이 로드맵의 M2 ~ M8이 "**첫 세계의 장기적 완성**"이다.
- 그 뒤: 두 번째 세계 / 세계별 Growth Grammar → Inter-world → Dimension → Transcendence / Multiverse
- 같은 종류의 "장소 하나 추가"를 무한히 반복하지 않는다(WB-0023 결정 3). M2 ~ M8에서 새 장소는 메인 서사가 요구할 때만 더한다.
