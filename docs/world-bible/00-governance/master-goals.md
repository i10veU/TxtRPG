## 1. SGMG-01 — 세계관 최강자가 되는 대서사 RPG

### 1.1 공식 정의 (소유자, WB-0029)

> TxtRPG는 방대한 콘텐츠와 확장 가능한 세계관을 바탕으로, 플레이어가 약한 출발점에서 시작해 세계의 비밀과 역사를 알아가고, 인물·세력·사건과 상호작용하며 성장한 끝에 세계관 최강자가 되는 경험을 제공하는 텍스트 RPG다. 플레이어는 기승전결이 완성된 대서사를 경험하고, 최종 도전과 결말을 통해 자신의 성장과 선택이 의미 있었다는 강한 성취감과 만족감을 얻는다.

### 1.2 게임 완결의 정의

다음 일곱 조건이 **모두** 충족되어야 완결이다.
1. **세계관의 풍부함:** 탐험할 지역, 역사와 비밀, NPC와 세력, 사건과 퀘스트가 충분히 쌓여 있다.
2. **완결된 기승전결:** 도입 → 성장 → 갈등의 심화 → 최대 위기 → 최종 결전 → 결말이 하나의 서사로 이어진다.
3. **납득 가능한 최강자 등극:** 레벨 숫자가 아니라 실제 도전의 극복, 능력의 성숙, 세계에 대한 영향력과 결과로 증명된다.
4. **플레이어의 주도성:** 메인 서사가 있어도 관심사에 따라 세계를 탐색하고 자신만의 목표와 방법을 발견할 수 있다.
5. **선택의 결과:** 정보·판단·행동이 실제 사건과 세계 상태를 바꾸고, 플레이어가 그 결과를 확인할 수 있다.
6. **감정적 보상:** 결말이 지나온 고난, 쌓은 지식, 맺은 관계, 감수한 위험을 의미 있게 회수한다.
7. **확장 가능성:** 기본 게임은 완결된 작품이되, 새 지역·신화·세력·서사를 더할 기반을 보존한다.

기본 출시판은 하나의 거대한 서사를 완결하고 최강자 등극까지 구현한다. 세계 전체의 콘텐츠를 영원히 완성할 필요는 없다.

**최종 판정 질문:** 플레이어가 이 세계에 처음 발을 들인 순간부터 최강자가 되어 결말에 도달하는 순간까지, 충분히 풍부하고 일관된 콘텐츠와 성장, 선택의 결과를 경험했으며, 마지막에 자신이 이 세계의 정점에 섰다는 강한 만족감을 얻는가?

## 2. 계층 규칙

| 계층 | 뜻 | 이 문서의 표기 |
|---|---|---|
| SGMG | 게임이 궁극적으로 어떤 작품이어야 하는가 | SGMG-01 |
| GMG | 큰 목표 영역(세계관·서사·성장·콘텐츠·시뮬레이션·주도성·출시) | GMG-01 ~ GMG-07 |
| SuMG | 각 영역을 완성하는 중간 단계 | SuMG-xx.y |
| MG | 완료 조건과 검증 방법이 명확한 실현 가능한 목표 | MG-001 ~ MG-084 |
| 구현 작업 | 코드·데이터·콘텐츠 변경 단위 | 이슈·PR·V2-Core-NNN·`roadmap.md`의 단계 행 |

- **상위는 하위의 개수로 판정하지 않는다.** 통합 검증이 필요하다.
  - 예: NPC를 많이 더해도 세계관과 서사에 의미 있게 작용하지 않으면 GMG-04는 달성되지 않는다.
- **목표 추가의 기준.**
  - 상위 목표에 필요하지 않은 하위 목표는 추가하지 않는다.
  - 새 하위 목표는 기존 계층 아래에 추가할 수 있고, 필요하면 GMG·SuMG도 새로 만든다.
- **구현 작업과 이슈.**
  - 구현 작업은 실행 가능한 MG에만 연결한다.
  - 실행할 MG는 목적, 선행 조건, 범위와 범위 밖, 산출물, 완료 기준, 검증 방법, 의존성, 위험을 갖춘다(§7의 형식).
  - 너무 큰 MG는 하위 MG(예: MG-046.1)로 나눈다.
  - **모든 MG를 GitHub Issue로 만들지 않는다.** 착수할 때 코드와 World Bible을 다시 확인해 구체화하고, 필요한 이슈만 만든다.
- **기존 결정 방식은 그대로다.**
  - 정본 등급과 승격(`canon-policy.md`), 위임 결정의 경계(WB-0018), 소유자 보류 항목.
  - MG가 보류 항목에 닿으면 그 MG는 소유자 결정 전까지 **보류**다.

SGMG-01을 기존 정본·원칙과 맞대어 본 결과다. 모순으로 확정하지 않고 **검토 대상**으로 둔다. 어느 것도 이 문서가 결정하지 않는다.

## 4. GMG · SuMG · MG와 현재 상태

상태 표시:
- **완료**: 구현·검증 근거가 있다.
- **부분**: 기반이 구현되어 있으나 MG의 완료 조건 전체는 아니다.
- **진행 중**: 열린 목표·PR이 있다.
- **미착수**
- **보류**: 소유자 결정 또는 Hard Gate.
- **검토**: §3과 얽힌다.

근거의 #는 GitHub 이슈·PR, D-는 `CORE_CONTRACTS.md`의 결정, WB-는 이 저장소의 결정 기록이다. **완료로 적은 것은 MG 문장이 요구하는 범위를 지금 구현이 충족한다는 뜻이다.** SGMG-01의 규모에서 다시 볼 수 있다.
