# 명명 지침

> 지위: **`Canon` 원칙** (WB-0017, 2026-10-04) — 아래 "정본" 절의 G-01 ~ G-10 문구만. 작업용 가정은 `Draft`, 미결은 미결이다.
> 근거·대안·이름의 층·대상별 구조·명명 도구 양식·검사 목록: `canon-review/naming-guidelines-recommendations.md`.
> 상위 정본: 명명 원칙(WB-0013, `design-principles.md`), 주제 원칙(WB-0007).

## 정본 (`Canon`, WB-0017)

| 번호 | 정본 문구 |
|---|---|
| G-01 | 한 대상은 여러 이름을 동시에 가질 수 있다 — 일반명사, 고장 이름, 공식 이름, 바깥 이름, 별칭, 옛 이름. 대상마다 필요한 층만 있다. |
| G-02 | 이름은 세계의 진실이지만, 이름을 아는 것은 출처를 통해 얻는 캐릭터의 지식이다. 새 생은 앞선 생이 알던 이름을 물려받지 않는다. |
| G-03 | 출처마다 이름이 다르거나 낡았을 수 있다. 공식 이름은 왕국의 중심에 가까울수록 얻기 쉽다. |
| G-04 | 세계는 이름이 퍼지기 전까지 사람을 역할이나 별칭으로 부른다. 별칭은 다른 이들이 기억하는 행적·출신·역할에서 생긴다. |
| G-05 | 고유명은 다음 순서로만 정한다: 대상 유형의 이름 구조 → 그 문화의 명명 도구 → 후보 이름 → 이름 목록 등록과 검사 → 정본 결정. 명명 도구가 없으면 일반명사·묘사형 이름을 쓴다. 문화마다 명명 도구를 하나씩 두며, 도구들 사이의 관계는 미결이다. |
| G-06 | 한국어 텍스트에서 일반명사·묘사형 이름·별칭은 뜻으로 쓰고, 명명 도구에서 나온 고유명은 소리로 쓴다. |
| G-07 | 현실의 문화나 다른 작품의 이름을 그대로 가져오지 않는다. 현실의 전통에서 영감을 얻을 때는 출처 우선순위를 지키고 서로 다른 전통을 뭉뚱그리지 않는다. |
| G-08 | 이름은 시간에 따라 바뀌고, 옛 이름은 기록과 전설에 남는다. 사건과 시대의 이름은 대개 나중에 기억하는 이들이 붙이며, 관점마다 다를 수 있다. |
| G-09 | 세계마다 명명 체계가 따로 있다. 세계 사이의 이름이 비슷해도 그것만으로 연결을 뜻하지 않는다. |
| G-10 | 명명 지침은 이름이 초자연적 힘을 갖는가에 대해 어떤 입장도 전제하지 않는다. |

## 작업용 가정 (`Draft`, 정본 아님)

| 번호 | 작업용 가정 |
|---|---|
| NG-W1 | 사람 이름의 자리: 개인 이름 + (문화가 고르는) 소속 표지 + 별칭 + 직함 |
| NG-W2 | 명명 도구 양식은 §4.2를 쓴다 |
| NG-W3 | 소리 이름은 대체로 2–4음절, 같은 문화 안에서 첫 음절이 겹치지 않게, 한국어 낱말과 우연히 같아지지 않게 |
| NG-W4 | 새 고유명은 §8의 검사 목록을 거친다 |
| NG-W5 | 정해진 이름은 이름 목록(`canon-review/name-registry.md`, 첫 이름이 생길 때 만든다)에 층·출처·등급과 함께 적는다 |
| NG-W6 | 첫 명명 도구는 *성읍이 속한 강 북쪽 지역의 문화*부터 만든다 — 다음 콘텐츠(성읍)가 이름을 가장 먼저 요구하므로. 변경은 계속 일반명사를 쓴다 |

## 미결

| 번호 | 미룰 것 | 왜 |
|---|---|---|
| NG-O1 | 모든 실제 고유명 | 명명 도구가 먼저 (G-05) |
| NG-O2 | 문화별 언어·음운의 실제 내용, 문화 사이의 언어 관계 | O-16 (언어·문화의 기원) |
| NG-O3 | 참이름 같은 숨은 층의 존재 | Q-5, WB-0009 범위 밖 |

| NG-O5 | 별칭이 생기는 조건·범위 | 게임 설계 (명성·평판 시스템) |

## 이름의 층 (G-01을 풀어 쓴 것 — 설명용)

① 일반명사 · ② 고장 이름 · ③ 공식 이름 · ④ 바깥 이름 · ⑤ 별칭·칭호 · ⑥ 옛 이름. 한국어 표기에서 ①⑤는 뜻으로, 명명 도구에서 나온 고유명은 소리로 쓴다(G-06).
