# 양식

새 설정 항목은 아래 양식 중 하나를 복사해서 쓴다. 모든 양식에 공통으로 들어가는 머리말:

```
> 등급: Draft | Provisional | Canon | Research | Deprecated   (00-governance/canon-policy.md)
> 구현 ID: — (구현되지 않음) | `loc_…`, `npc_…`, `org_…`, `item_…`, `fact_…`
> 연결: 이 항목과 이어지는 기존 요소 (최소 하나, 설계 원칙 §11)
> 근거: 결정 기록(WB-…), 연구 자료, 구현 위치
```

| 양식 | 쓰는 곳 |
|---|---|
| `region.md` | 지역·장소 (`03-geography/`) |
| `faction.md` | 조직·세력 (`04-peoples-and-factions/factions.md`의 항목이 커질 때) |
| `character.md` | 인물 (`04-peoples-and-factions/`) |
| `event.md` | 역사적 사건·진행 중인 사건 (`02-world/history-timeline.md`) |
| `item.md` | 고유한 물건·유물·자원 |

## 공통 원칙

- **진실과 정보를 나눈다.** "진실" 칸은 세계에서 실제로 일어난 일, "정보" 칸은 사람들이 아는·믿는 것(소문·기록·전설)이다.
  둘이 다를 수 있고, 그 차이가 이야기의 재료다 (설계 원칙 §6, `01-foundations/world-structure.md`).
- **시간에 따라 변한다.** 플레이어가 없어도 무엇이 변하는지 적는다 (설계 원칙 §10).
- **모르는 것은 미결로 둔다.** 칸을 채우려고 설정을 지어내지 않는다. 비워 두고 `99-open-questions.md`에 질문을 올린다.
- 엔진 규칙(수치·판정·저장 형식)은 적지 않는다. 그것은 `CORE_CONTRACTS.md`의 영역이다.
