# 세계 개요

> 지위: **일부 `Canon`, 대부분 미결.** 문장마다 근거를 적는다. `Canon`은 승인된 범위만이다 (2026-10-04, WB-0007 ~ WB-0015).

## 정본 (`Canon`)

| 내용 | 근거 |
|---|---|
| 「무명의 연대기」는 이름 없는 이들이 남긴 결과가 세계의 역사가 되는 이야기다. 이름은 세계가 기억할 때 생긴다 (*주제 원칙*) | WB-0007 |
| 이 세계에는 초자연 현상이 존재한다 (그 원천·법칙·종류·쓰는 자·세계/차원과의 관계는 미결) | WB-0009 |
| 남쪽 변경의 기술은 중세 수준이다 — 철제 무기와 도구, 물레방아, 나룻배, 양피지와 인장, 손으로 쓴 게시문. 기술 수준은 지역마다 다를 수 있다 | WB-0008 |
| 왕이 다스리는 왕국이 있다. 성을 가진 영주들이 땅을 나누어 다스리고 징집할 수 있다. 이 지역에서 영주의 실질적 지배는 강까지이고, 강 남쪽 변경은 명목상 왕국의 땅이지만 사실상 원로들의 자치다 | WB-0010 |
| 왕도는 왕권의 자리이자 왕국에서 가장 큰 시장이며, 강 건너 북쪽으로 걸어서 닷새 거리다 | WB-0011 |
| 왕국의 먼 국경에서 소란·분쟁이 존재한다 (원인·참여자·진실·결과는 미결) | WB-0012 |
| 장소와 사람에게는 고유명이 있지만 변경 사람들은 일반명사로 부른다. 고유명은 정보로 발견된다 (*명명 원칙*) | WB-0013 |
| TxtRPG는 여러 세계와 장르를 담는 메가월드다. 세계마다 성장·능력 체계가 다를 수 있다 (*방향*) | WB-0014 |
| 남쪽 변경의 장소·인물·최근 역사 — 문구 C-01 ~ C-24 (`03-geography/frontier-region.md`, `04-peoples-and-factions/characters.md`) | WB-0015 |

## 알려진 것 (`Provisional` — 구현된 범위, 정본 검토 전)

- 플레이는 왕국의 **남쪽 변경**에 있는 작은 마을에서 시작한다.
- 영주의 징집령은 16세가 넘은 남자를 성으로 부른다. 수배서와 상단 조합의 공고가 강 건너 게시판에 붙는다.
- **은화**가 통용된다 (통화의 이름·단위는 Q-11).
- 사람들은 철검과 등불을 쓰고, 약초를 달여 약을 만든다. 초자연을 직접 보여 주는 콘텐츠는 아직 없다.

세부 목록과 구현 ID는 `canon-review/v2-implemented-content.md`.

## 미결 (소유자 결정 필요 — 일부는 의도적으로 미룸)

- 세계의 이름 (Q-1), 종족 구성, 신앙과 신의 실재 (Q-4), 이름·초월의 법칙 (Q-5).
- 초자연의 원천·법칙·종류·쓰는 자, 세계·차원과의 관계 (WB-0009 범위 밖).
- 실재하는 '연대기'의 존재와 본질, 새 생이 일어나는 이유 (WB-0005, WB-0007 범위 밖).
- 왕국·왕조·영주·왕도의 이름과 세부, 왕권의 성격 (WB-0010, WB-0011 범위 밖).
- 국경 분쟁의 원인·참여자·진실·결과, 남쪽 변경의 더 남쪽 (WB-0012 범위 밖).
- 과거 문명과 폐허의 기원, 절대 연대 (WB-0008 범위 밖).

"샘의 정령" 같은 초자연에 관한 이야기의 진위, 초자연이 드문지 흔한지는 정본이 아니다. 추천안(`canon-review/priority-a-recommendations.md` §7)의
"드물고 숨어 있다"는 승인되지 않았으므로 `Draft`로 남는다.
