# 세계 속의 체계 — 경제·능력·정보

> 이 문서는 체계의 **사회적 의미**를 다룬다. 계산 규칙은 `CORE_CONTRACTS.md`가 정한다.
> 등급: 아래 "알려진 것"은 `Provisional`, 나머지는 미결.

## 경제

- **알려진 것**: 은화. 등불 5, 철검 3, 빵 1, 연고 3(감사받은 이에게 1), 뱃삯 3, 정화초를 방앗간에 팔면 2.
  도적이 사라지면 교역이 되살아난다. 마을의 신뢰는 값을 바꾼다.
- **정본**: 숲속 샘의 물가에 자라는 정화초는 이 근방에서 귀한 풀이다 (C-17, WB-0015). 가격은 정본이 아니다(게임 값).
- **미결**: 통화 체계(은화 외의 단위), 지역별 가격 차이와 그 이유, 희소 자원의 분포 (설계 원칙 §4).

## 능력

- **알려진 것**: 여섯 가지 능력치(힘·민첩·체력·지능·지혜·감각), 기술(검술·조사·약초학)과 숙련 단계, 정찰자의 밤눈과 조사의 재능,
  체력(스태미나)을 쓰는 기술. 약초꾼에게 약초학을 배울 수 있다(스승·전승의 첫 예).
- **정본**: 이 세계에는 초자연 현상이 존재한다 (WB-0009).
- **미결**: 능력의 사회적 가치와 희소성, 스승·전승의 구조 (설계 원칙 §5). 초자연의 원천·법칙·종류, 그것을 *사람이 쓸 수 있는가*와
  그 성장체계(WB-0009 범위 밖 — 구현은 `feature/v2-core`의 성장체계 결정 D-91을 따른다).
  연구 문서의 축(`인간 → … → 전설 → 신화 → 초월`)을 세계의 법칙으로 둘지 (Q-5).

## 정보

- **알려진 것**: 세계의 진실과 캐릭터의 지식은 별개다. 소문·증언·기록·전설은 출처와 신뢰도를 가지고,
  전설은 시간이 지나 생기며, 직접 본 진실로 바로잡을 수 있다. 바로잡은 이야기는 세계의 기록이 되어 다른 이에게도 전해진다.
- **미결**: 기록을 관리하는 조직(서기·신전·길드)의 존재, 문자와 교육의 보급.
