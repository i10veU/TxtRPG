# Phase 264 — 조직 연계 NPC 목표 동역학

## 목표

Phase 263에서 조직이 독립적으로 의사결정하기 시작했기 때문에, NPC의 개인 목표가 조직 세계와 완전히 분리되어 있으면 자율성은 표면적인 수준에 머문다. Phase 264에서는 NPC 목표를 소속 조직의 우선순위와 연결하고, 목표의 중단·재개·재계획·후속 목표를 상태로 보존한다.

## 핵심 변경

### 1. 목표 체인

NPC마다 짧은 목표 체인을 가진다. 현재 목표가 완료되면 completedGoals에 기록한 뒤 다음 목표를 자동으로 선택한다. 따라서 목표 완료가 NPC 행동의 종착점이 아니라 다음 행동의 원인이 된다.

### 2. 조직 압력

각 조직은 하루에 한 번 세계 상태를 평가하면서 goalPressure를 -2~2 범위로 계산한다.

- 2: 조직이 해당 NPC의 목표를 강하게 지원하며 진행도가 빠르게 누적된다.
- 0~1: 정상 진행.
- -2: 조직의 현재 우선순위와 개인 목표가 충돌하여 목표가 일시 중단된다.

조직 압력은 기존 시장·치안·곡물·행정 신뢰·소문·긴장 상태에서 계산되므로 별도 랜덤 수치가 아니다.

### 3. 목표 중단과 재개

목표가 조직 압력 때문에 중단되면 blocked, blockedReason, blockedAt가 저장된다. 압력이 회복되면 같은 목표를 다시 활성화한다.

### 4. 재계획

중단 상태가 하루 이상 지속되면 현재 목표를 포기하고 목표 체인의 다음 목표로 전환한다. 재계획 횟수와 중단된 목표는 completedGoals에 남는다.

### 5. 런타임 일치

브라우저의 HTML 런타임에도 npc-goals.js를 명시적으로 로드하고 초기화한다. 기존에는 Worker가 목표 모듈을 로드했지만 브라우저 메인 스레드 HTML에는 해당 스크립트가 빠져 있어 런타임 간 목표 상태가 달라질 수 있었다.

## 검증

tests/phase264-goal-dynamics.js에서 목표 초기화, 조직 압력, 목표 진행, 중단·재개, 지속 중단 시 재계획, 목표 완료 후 후속 목표 전환, 저장/정규화 및 365일 반복 시뮬레이션을 검증한다.

브라우저 smoke test는 NPC 패널에서 목표 상태가 초기화되는지 확인하고, 실제 Worker 액션 이후 목표 진행도가 증가하는지를 확인한다.
