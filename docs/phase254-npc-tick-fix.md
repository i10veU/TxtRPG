# Phase 254 — NPC 틱 중복 처리 수정

## 문제

기존 NPC 시뮬레이션은 플레이어 행동 전후의 경과 시간만으로 30분 틱을 계산했습니다. 시뮬레이션된 마지막 시각을 상태에 기록하지 않아 여러 짧은 행동이 같은 30분 구간에 반복되면 동일한 NPC 틱이 여러 번 적용될 수 있었습니다.

## 수정

- world.npcSimulationMinute 상태 추가
- NPC 시뮬레이션이 마지막 처리 시각 이후의 30분 경계만 실행
- 기존 세이브에 커서가 없으면 현재 월드 시각을 초기 커서로 사용
- 커서가 현재 시각보다 미래에 있는 비정상 세이브를 현재 시각으로 보정
- 상태 스키마를 3으로 증가
- Worker와 메인 스레드 fallback이 동일한 커서 기반 시뮬레이션 사용

## 검증

- 동일 시각에서 NPC 시뮬레이션 반복 호출 시 효과 중복 없음
- 30분 경계 도달 시 정확히 한 번 실행
- 15분 경과 후에는 틱을 실행하지 않음
- 기존 Schema 2 세이브에서 npcSimulationMinute 자동 복구
- JavaScript syntax 검사와 기존 Core regression 유지
