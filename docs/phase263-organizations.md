# Phase 263 — 조직 자율 의사결정

## 목적

세력 관계 수치만 변하는 구조에서 벗어나, 조직이 하루에 한 번 세계 상태를 관찰하고 독립적인 결정을 내리도록 확장한다.

## 구현

- `web/core/organization-world.js` 추가
- 6개 조직의 일일 의사결정 모델 구현
- 조직 결정 결과를 `world.organizations`에 영속화
- Worker / fallback runtime에서 동일한 조직 시뮬레이션 사용
- schema 5 마이그레이션과 기존 세이브 호환
- 7번 PC 오버레이에서 조직의 최근 결정 표시
- Phase 263 조직 회귀 테스트 추가

## 현재 조직

| 조직 | 주요 반응 |
|---|---|
| 상인회 | 곡물 공급 / 시장 재고 |
| 경비대 | 긴장 / 치안 |
| 기록관 | 행정 신뢰 / 소문 |
| 농촌 대표단 | 곡물 공급 |
| 여관망 | 소문 / 긴장 |
| 노동자 조합 | 치안 / 긴장 |

## 플레이 루프

세계 상태 → 조직 판단 → 조직 행동 → 세계 상태 변화 → NPC/경제/사건 반응

조직은 플레이어가 직접 명령하지 않아도 하루 단위로 행동한다.

## 한계

현재 조직은 단일 조건 기반 결정만 수행한다. 조직 간 협상, 경쟁, 연합, 장기 전략, 조직별 자원·지도부·내부 분열은 아직 구현하지 않았다.

## 검증

- 6개 조직 초기화
- 일일 1회 결정 cadence
- 같은 날 중복 결정 방지
- 다음 날 재결정
- 시장 재고/치안/소문 변화
- schema 5 정규화
- CI 회귀 테스트 연결
