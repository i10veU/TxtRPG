# Phase 260 — 동적 곡물 경제

## 목적

기존 세계 상태의 `grainSupply`, `tension`, `security`가 실제 시장 가격과 거래 가능 재고에 영향을 주도록 경제 계층을 추가했다.

## 구현

- `web/core/economy-world.js` 추가
- 곡물 가격을 공급·긴장·치안으로 계산
- 일 단위 시장 재고 시뮬레이션
- `곡물`, `시세`, `곡물 가격`, `시장 가격` 조회 명령
- `곡물 구매 N`, `곡물 사 N`, `곡물 판매 N`, `곡물 팔 N` 거래 명령
- 거래량을 경제 상태에 기록
- 거래 시 상인회 관계에 작은 변화 적용
- Worker와 fallback runtime에서 동일 경제 로직 사용
- 상태 schema를 4로 올리고 기존 세이브에 경제 기본값 자동 적용
- STATUS 오버레이에 곡물 가격/시장 재고 표시

## 세계 반응

곡물 공급이 낮거나 긴장도가 높아지면 가격이 상승한다. 시장 재고가 부족하면 소문 압력이 증가한다. 플레이어의 거래는 시장 재고와 개인 자금·소지품을 동시에 변경한다.

## 검증

- 전체 web JavaScript syntax 검사
- 기존 Phase 251~259 회귀 테스트
- Phase 260 경제 회귀 테스트
- 기존 저장 데이터의 schema 4 정규화 테스트
- 가격 일일 갱신 중복 실행 방지 테스트
- 구매/판매 상태 전이 테스트
- Browser smoke CI 연계
