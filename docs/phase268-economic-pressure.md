# Phase 268 — 경제 압력과 세력·사건 연계

## 구현

- 곡물 가격과 시장 재고가 임계값에 도달하면 `marketCrisis` 세계 신호를 생성한다.
- 경제 위기는 하루 한 번만 세력 관계에 압력을 가한다.
- 상인회는 공급 통제력으로 관계가 상승하고, 농촌·노동자·여관망은 생활비 압박으로 관계가 하락한다.
- 위기 발생 시 긴장도와 소문 압력이 상승한다.
- `시장` 상태 패널에서 안정/압박/위기를 확인할 수 있다.
- 신규 사건 `market-crisis`를 추가했다.
- 사건 선택은 배급, 장기 공급 계약, 장부 공개로 나뉘며 각각 다른 세력 관계와 경제 상태를 만든다.
- 기존 저장 데이터에는 `economy.pressureDay`, `flags.marketCrisis`, `eventSignals`가 없을 수 있으므로 자동 기본값을 적용한다.

## 게임 루프

`경제 상태 → 시장 압력 → 세력 관계 변화 → 소문/긴장 → 시장 위기 사건 → 플레이어 선택 → 경제·세력 상태 변화`

## 검증

- 전체 JavaScript syntax 검사 경로 유지
- 기존 Phase 251–267 회귀 테스트 유지
- Phase 268 경제 압력 테스트 추가
- 위기 임계값 및 하루 1회 적용 검증
- 경제 기반 사건 생성 및 Consequence 검증
- 안정 시장에서 위기 신호가 생성되지 않는지 검증
