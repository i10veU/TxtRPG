# Phase 252 — NPC 자율 시뮬레이션

## 목표

플레이어의 명령에 반응하는 NPC에서 벗어나, 시간이 흐르면 NPC가 자신의 일정과 목표에 따라 독립적으로 이동하고 행동하는 세계 시뮬레이션의 첫 단계를 구현한다.

## 구현

- NPC별 일정(schedule) 데이터 추가
- NPC별 목표와 현재 위치를 상태로 유지
- 30분 단위 시뮬레이션 틱 구현
- 플레이어 행동으로 경과한 시간을 기준으로 NPC 틱을 재생
- Worker에서 NPC 시뮬레이션 실행
- Worker를 사용할 수 없는 fallback 경로에서도 동일한 시뮬레이션 실행
- NPC의 이동과 행동 결과를 세계 상태에 반영
- 중요한 NPC 행동을 시스템 로그로 기록
- UI에 NPC의 현재 위치와 최근 행동 표시

## 현재 NPC 행동 모델

각 NPC는 다음 정보를 가진다.

- name
- role
- goal
- place
- trust
- schedule
- lastAction
- lastTick

schedule은 시간대별 목적지와 행동, 선택적 세계 효과를 정의한다.

예:

```text
06:00–12:00 마라 → 시장 → 시장 거래
12:00–15:00 마라 → 골목 → 창고 장부 확인
18:00–24:00 요나스 → 부두 → 야간 선박 감시
```

## 세계 효과

현재 NPC 행동은 작은 단위의 세계 변화를 발생시킨다.

- 곡물 생산/거래 → grainSupply
- 경비 순찰 → security
- 시설 수리 → security
- 야간 부두 활동 → rumorPressure
- 일부 회의/활동 → tension

아직 경제 시스템이나 조직 시스템과 직접 연결하지 않았으며, 다음 단계에서 관계와 원인-결과망을 확장한다.

## 시뮬레이션 경계

NPC는 플레이어와 같은 게임 시간을 공유한다. 플레이어 행동 전후의 절대 시간 차이를 계산하고 그 구간의 30분 틱을 Worker에서 순차적으로 재생한다.

따라서 플레이어가 10분 조사하면 최소 10분의 세계 시간이 진행되고, 480분 수면하면 그 사이의 NPC 일정도 함께 진행된다.
