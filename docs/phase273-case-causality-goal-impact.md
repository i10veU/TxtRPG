# Phase 273 — 사건 결과와 NPC 목표 압력

## 목적

교역로 후속 사건의 선택 결과가 지역 경제에만 머물지 않고 조직 압력과 소속 NPC의 장기 목표에도 반영되도록 연결한다.

## 구현

- `trade-route-aftershock`의 `audit` 선택은 기록관 압력을 높이고 상인회 압력을 낮춘다.
- `renew` 선택은 상인회와 노동자 조합의 목표 압력을 높인다.
- `local` 선택은 농촌 대표단과 노동자 조합의 목표 압력을 높인다.
- 압력은 기존 `[-2, 2]` 범위로 제한한다.
- 영향받은 조직의 NPC 목표를 즉시 재검토해 우선순위 상승이나 목표 중단을 반영한다.

기존 지역 시장·교역로 수치와 사건 인과 기록은 변경하지 않는다.

## 검증

- Phase 273 사건 인과/NPC 목표 영향 회귀 테스트
- 기존 비브라우저 회귀 테스트 전체
- JavaScript 문법 및 `git diff --check`
