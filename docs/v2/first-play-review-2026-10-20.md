# 초반 플레이 검토와 진행 안내 개선 — 2026-10-20

Issue #403. 기준은 V2-Core-159, `c6a5df5`다. 최신 Claude 작업의 서술과 그림을 유지하면서 초반 선택의 흐름을 검토했다.

## 범위와 방법

실제 Chromium에서 떠돌이 새 게임 → 원로에게 폐허 질문 → 시장 → 등불 구매 → 약초꾼에게 배앓이 질문 → 마을 귀환 → 폐허 도착을 버튼으로 진행했다. 1360×900과 390×844 화면, 밝은 테마와 어두운 테마를 확인했다. 수정 후 IndexedDB 저장 → 새로고침 → 불러오기도 진행했다.

이것은 개발자가 목표 이해, 선택의 발견, 선택 후 변화의 인지, 문장과 화면의 읽기 흐름을 살핀 정성 평가다. 사람의 감정적 만족이나 결말의 재미를 측정한 실험은 아니다. J3 재시험 통과를 선언하지 않는다.

## 관찰

| 평가 축 | 확인한 장점 | 확인한 문제 |
|---|---|---|
| 출발 동기 | 징집을 피해 이름을 두고 온 프롤로그가 현재 처지와 첫 행동을 연결한다 | 전체 장기 서사의 만족감은 이번 짧은 경로로 판단하지 않았다 |
| 호기심과 정보 | 원로의 불빛 이야기에서 폐허 조사로 이어지고, 약초꾼은 우물의 별도 단서를 제공한다 | 전해 들은 정보와 직접 확인한 정보의 전달 방식은 계속 살필 필요가 있다 |
| 진행의 보상 | 구매 결과 카드가 등불 획득과 지출을 함께 보여 준다 | 등불을 산 직후에도 ‘등불부터 구한다’는 목표가 남는다 |
| 선택지 위계 | 실행 가능한 행동의 번호, 시간, 판정 확률이 읽힌다 | 시장에서도 두목 대면과 원로 대화가 같은 크기의 비활성 카드로 이어진다 |
| 시각과 가독성 | 책의 표지, 장소 그림, 장면·목표·선택지의 구분이 일관된다 | 작은 화면에서 비활성 카드의 비중을 낮추면 현재 선택이 더 선명해진다 |

## 구현한 개선

- 이미 들은 폐허 소문과 내 소지품·야시 특성·위치를 기존 Condition 평가기로 읽는다.
- 등불을 구한 시장에서는 마을 귀환, 준비한 상태에서는 폐허 방문, 폐허에 도착하면 조사를 안내한다.
- 더 진행된 기존 목표(발견, 해결, 후반 서사)는 그대로 우선한다. 소문을 듣지 않은 인물에게 폐허 목표를 노출하지 않는다.
- 일반 행동의 비활성 버튼은 펼쳐진 ‘지금은 할 수 없는 일’ 묶음으로 옮긴다. 기존 View의 버튼, 고정 잠김 문구, 키보드 번호는 보존한다.
- 새로운 세계 사실이나 인물, 저장 필드, 시간·가격·전투·난수 규칙을 추가하지 않는다.

목표가 실제 준비와 도착을 인정하도록 해서 작은 행동에도 진척을 느끼게 하는 선택이다. 모든 비활성 행동을 숨기면 나중에 가능한 행동을 발견하기 어려워지므로, 별도 묶음 안에 계속 보여 주었다.

## 검증

- 수정 전 집중 Node 테스트에서 구매 후 목표가 바뀌지 않는 실패를 재현했다.
- 수정 후 개발 브라우저 환경의 Node v26에서 V2 회귀 **123/123**이 통과했다. 정찰자 우회, 소문 미획득, 기존 다음 단계 우선, 조회의 불변성도 검사했다.
- 실제 Chromium의 390px 화면에서 구매 후 목표 변경·획득 카드·키보드 첫 선택·IndexedDB 저장과 복원·귀환과 도착을 확인했다. 가로 넘침은 없었다.
- CI의 Node 22와 전체 Chromium 검증 결과는 PR에 기록한다. 추가 브라우저 spec은 실제 버튼, 저장 복원, 정찰자, View 버튼 수와 번호를 검증한다.

## 다음 평가 지점

폐허의 시간 경과 위험을 처음 겪는 사람이 준비와 퇴각을 납득하는지, 단서가 늘어난 뒤 우물·폐허 중 자기 목표를 고르기 쉬운지, 반복 조사 후 성공이 충분한 보상으로 느껴지는지를 이어서 확인한다. 후반 결전과 장기 성장의 재미는 별도 완주 평가가 필요하다.
