## 기존 측정의 해석

2026-10-14 M7 측정은 40개 세계 × 4개 주사위 × 다섯 정책 × 두목 생사, 120일 경력이다(`tests/v2/measure/story-careers.mjs`). hero 정책은 수호자 99%, 왕국의 이름 94%(중앙값 38~39일)에 닿았다. 대비로 버티는 결말은 0%, 영주의 깃발 결말은 lord 정책에서 6%였다. 60일 뒤 행동 종류 G4는 중앙값 6~7로 목표 8에 못 미쳤다. 모든 정책의 사망은 경력당 0.38로 기록되었고, 셋째 날 첫 호위에 몰렸다. 이 값들은 해당 정책·표본의 관찰치이며 모든 플레이어의 도달률이나 확률을 뜻하지 않는다.

기존 보고의 `lord`·`hero` 경력 5%는 강 남쪽에서 은화가 3 미만인 상태에 있었다. 측정 정책은 기존 원로의 통행 편지를 사용하지 않았다. 그러므로 이 5%만으로 게임 전체의 통행 불능이나 보편적 softlock을 단정할 수 없다. M8에서 편지 사용을 포함한 경로와 실제 UI 선택을 다시 측정하고, 경제 조정 여부를 그 뒤 판단한다.

Issue #349의 대기시간과 저장 UI 결함은 재현 가능한 기능 오류다. 새 회귀 테스트와 실제 Chromium·IndexedDB 지연 경로, 정확한 head의 CI 결과는 PR #350에 기록한다.
