# Phase 262 — 구조화된 NPC 목표

## 목적

기존 NPC의 `goal` 문자열을 실제 시뮬레이션 상태로 승격하여, NPC가 목표를 갖고 행동하고 목표를 달성하는 세계 루프를 만든다.

## 구현

- `web/core/npc-goals.js` 추가
- NPC별 `goalState` 생성
- 목표 진행도 / 목표량 / 상태 / 마지막 진행 시각 / 완료 시각 저장
- 일정에 진입할 때 목표 진행도를 1씩 증가
- 목표 달성 시 `complete` 상태로 고정
- 목표 달성 시 소속 세력 관계에 작은 긍정 효과 반영
- `인물목표`, `npc목표`, `목표목록` 명령 추가
- NPC 오버레이에 목표 진행도 표시
- Worker와 브라우저 runtime에서 목표 모듈 로드

## 현재 모델

현재 목표는 NPC별 하나의 활성 목표를 기준으로 한다.

```text
NPC 일정 진입
→ 목표 진행 +1
→ target 도달
→ 목표 완료
→ 세력 관계에 작은 결과
```

## 한계

목표 실패, 우선순위 변화, 목표 간 경쟁, 관계에 따른 목표 변경, 장기 목표 교체는 아직 구현하지 않았다. 다음 단계에서는 조직 의사결정과 관계망을 연결해 NPC가 세계 변화에 따라 목표를 바꾸도록 확장한다.

## 검증

- 모든 NPC의 goalState 생성
- 일정 진행에 따른 목표 증가
- 목표 완료 상태 전이
- 소속 세력 관계 결과
- 저장/정규화
- 플레이어 목표 조회 명령
- 40회 이상 장기 진행 회귀
- CI 연결
