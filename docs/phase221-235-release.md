# Phase 221–235 — 분기형 사건망

## 구현
- 추적 사건에 `branch` 상태를 추가했습니다.
- 사건마다 3개의 대응 경로를 생성합니다.
- 사건 유형별로 공식 절차, 협상, 은폐/위험 행동 등의 선택지가 달라집니다.
- 선택에는 결정론적 위험 판정이 적용됩니다.
- 성공/실패 결과가 사건 신뢰도, 현금, 법률 열, 세력 평판 등에 반영됩니다.
- 선택 결과는 `case_branch` 기록으로 연대기에 남습니다.
- 사건 상세/목록에서 현재 분기 상태를 확인할 수 있습니다.

## 명령
- `사건분기 <번호>` — 선택지 표시
- `사건분기 <번호> <선택>` — 선택 실행
- `<선택>`은 번호 또는 선택 ID를 사용할 수 있습니다.

## 저장 호환성
기존 Save Schema 91을 유지합니다. 신규 `branch` 필드는 기존 세이브에 없을 경우 자동으로 미결 상태로 처리되므로 별도 스키마 증가가 필요하지 않습니다.

## 검증
- Phase 206–220 테스트 + 분기 검증 PASS
- 전체 통합 시나리오 PASS
- Phase 206–220 장기 시뮬레이션 365일 PASS
- historySeq 1,185까지 단조 증가 확인
- Worker parity PASS
- JS syntax 검사 PASS

## 개발 의도
이 단계부터 사건은 단순히 `조사 → 증거 → 해결`하는 선형 콘텐츠가 아니라, 플레이어의 선택에 따라 위험·보상·법률·조직 관계가 달라지는 세계 상태 변화의 진입점으로 사용됩니다.
