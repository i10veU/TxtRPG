# Phase 256 — NPC 일정 효과와 알림 주기 분리

## 문제

기존 NPC 시뮬레이션은 30분 틱마다 일정의 효과와 알림을 함께 적용했다. 따라서 `announce: true` 일정은 같은 활동을 계속 수행하는 동안에도 30분마다 동일한 서술이 반복됐다.

효과 자체는 생산·순찰·수리처럼 일정 시간 동안 계속되는 행동으로 볼 수 있지만, UI 로그의 "이동했다", "수리했다" 같은 설명은 일정에 진입한 순간 한 번만 발생하는 편이 상태 변화와 더 잘 대응한다.

## 수정

첫째, 각 NPC에 현재 일정의 식별자(`activeRoutineKey`)를 저장한다.

둘째, 30분 틱에서 일정이 없으면 활성 일정 식별자를 비우고, 일정이 있으면 현재 일정과 직전 일정을 비교한다.

셋째, `effect`와 세력 신뢰 변화는 기존처럼 매 틱 적용한다.

넷째, `announce: true` 서술과 경계 확산 로그는 새로운 일정에 진입한 틱에서만 발생시킨다.

이 구조는 "행동의 지속 효과"와 "상태 전환을 알리는 텍스트"를 분리하므로 이후 소문, 생산, 수리, 경제 시스템의 시간 단위를 확장하기 쉽다.

## 검증

`tests/phase256-npc-routine-cadence.js`는 오전 7시의 오렐 일정을 두 틱 연속 실행한다.

7:00 진입 시 이동/수리 알림이 발생하고, 7:30에도 수리 효과는 계속 적용되지만 동일한 알림은 다시 생성되지 않는지를 검사한다.
